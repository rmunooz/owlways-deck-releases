# 🦉 Owlways Deck

Várias contas de jogos idle numa janela só, cada uma com o próprio login, leve e rodando mesmo com a janela escondida.

## Baixar
Vá em **[Releases → versão mais nova](../../releases/latest)** e baixe:
- **Windows:** `Owlways.Deck_…_x64-setup.exe`
- **Mac:** `Owlways.Deck_…_universal.dmg` (abra e arraste a coruja para Aplicativos)

O app avisa sozinho quando sair versão nova: é só clicar em **Baixar** e instalar por cima. As contas continuam logadas.

## Primeira abertura
O app ainda não tem assinatura digital, então o sistema pode avisar na primeira vez. É só confirmar que quer abrir.

> Este repositório guarda só os instaladores.
